# 티링크 프로모 스튜디오

> 현장사진만 올리면 AI가 티링크 기술 차별점을 근거와 함께 뽑아 **블로그 리뷰·카드뉴스**를 만들고 **가이드라인 51개 조건을 자동 검수**하는 마케팅 도구입니다.

- **과제:** AISH 5회 스마트워크톤 본선 트랙 A, 티링크 과제. "티링크의 제품과 기술적 차별점을 AI가 분석하고, 현장 사진과 제품 정보만으로 고객의 관심을 끌 수 있는 홍보 콘텐츠를 자동 생성하는 마케팅 솔루션"
- **대상 제품:** 티링크 비즈레코딩 + 티링크노트(종합리포트). 인터넷전화·휴대폰·PC 소프트폰 통합 녹취, STT·AI 통화요약, AES256 암호화
- **대상 사용자:** 티링크 마케팅 담당자(1차), 가이드라인을 받아 리뷰를 쓰는 체험단 블로거(2차), 도입 사례 콘텐츠가 필요한 티링크 영업 담당자(확장)
- **시연 영상:** 【업로드 후 기입】

---

## 1. 해결하는 문제

티링크 2026년 11월 홍보 가이드라인 1건에는 다음 **51개 조건**이 있습니다.

| 조건 | 개수 | 예시 |
| --- | --- | --- |
| 필수 키워드 (제목과 본문 모두) | 3 | 통화요약, 콜센터 프로그램, 업무자동화 |
| 서브 키워드 | 10 | 녹취, 경영대시보드, CRM, STT, 음성요약 등 |
| 태그 | 19 | #콜센터프로그램 #종합리포트 등 |
| 강조 미션 | 11 | 제목·첫 문단 키워드, 화면 이미지 5종 순서대로 소개, 보안 소개 등 |
| 추천 본문 구성 | 5 | 기존 영업관리의 문제 → 휴대폰·인터넷전화 동시 녹음 → AI 자동 기록과 요약 → 영업사원 관리 → 경영진 종합 리포트 |
| 하단 정보 | 3 | 홈페이지, 공식 블로그, 상담 문의 |
| **합계** | **51** | |

1. **작성·검수 부담:** 작성자는 51개 조건을 빠뜨리기 쉽고, 마케팅 담당자는 원고마다 51개를 눈으로 대조합니다.
2. **반복 작업:** 같은 기술 차별점(통합 녹취, STT·AI 통화요약, 티링크노트 종합리포트, AES256 암호화)을 채널과 독자에 맞게 매번 다시 풀어 씁니다.
3. **사진과 글이 따로 논다:** 가이드라인은 휴대폰 통화 화면 → 녹취 목록 → AI 통화요약 → 직원별 통계 → 종합리포트 순서를 요구하지만, 사진 고르기·배치·개인정보 확인은 수작업입니다.
4. **일반 생성형 AI는 세지 않는다:** 조건 충족 여부를 세지 않고, 자료에 없는 수치·최상급 표현을 알려 주지 않습니다.

## 2. 1단계 주요 기능 ↔ 구현 여부 ↔ 실측값

실측 조건: 기본 제품 자료·11월 가이드라인 + 화면 캡처 5장, 4회차(생성 effort low, 재생성 로직 포함) 기준.

| # | 1단계 주요 기능 | 구현 | 구현 내용 (화면 탭) | 실측값 (4회차) |
| --- | --- | --- | --- | --- |
| 1 | 기술 차별점 분석: 차별점 4~6개를 "기술 특징 / 고객 이익 / 자료 근거" 카드로, "일반 방식 vs 티링크" 비교표 | 구현 | ① 차별점 카드. 근거가 없으면 "확인 필요" 배지 | 카드·비교표 생성 |
| 2 | 현장사진 분석·배치: 사진 1~5장마다 보이는 것, 증명하는 차별점·미션, 배치 위치, 캡션·대체텍스트, 이름·전화번호 노출 시 흐림 처리 경고 | 구현 (경고까지. 자동 흐림은 없음) | ② 사진 분석·배치. "미션 증거" 배지 또는 "해당 미션 화면 아님", "개인정보 주의" 배지 | 사진 5장 분석. 사진 3·4·5는 미션 증거로 연결, 사진 1·2는 "미션이 요구한 화면(휴대폰 통화·인터넷전화 녹취 목록)이 아니라 대면 녹취 화면"으로 구분 |
| 3 | 콘텐츠 생성 + 자동 검수: 블로그 리뷰 초안(근거 출처 태그·협찬 표시), 카드뉴스 4장(PNG 다운로드), 51개 조건 검수표와 "확인 필요" 경고 | 구현 | ③ 블로그 리뷰(키워드 강조, 근거 태그, 협찬 표시, 본문 복사), ④ 카드뉴스(1080×1080 PNG), ⑤ 검수표 | 51개 중 48개(94%, 검수표 기준 자동 판정 충족률이며 정확도 아님): 코드 검사 40/40, 미션 8/11(AI 판정). 확인 필요 경고 4건. 4회차는 모든 필드 채워짐 |

4회차 생성 결과 예시

- 카드뉴스 1장: "녹음, 다시 듣나요? / 하루 1건만 놓쳐도 1년이면 240건의 영업 기회가 사라집니다."
- 카드뉴스 4장: "무료 상담 1877-3836 / 무료 상담 → 맞춤 설치·연동 → 종합리포트 자동 생성"
- 협찬 표시: "이 글은 티링크로부터 제품 정보와 서비스를 제공받아 작성되었습니다."
- 추가 점검(점수 미반영): 제목·첫 문단 키워드 7개 모두 ✓, 최상급 표현 0건

**이번에 만들지 않은 것 (1단계와 동일):** 블로그·SNS 자동 게시, 영상 생성, 다국어 번역, 회원가입·로그인, 게시 후 성과 분석

## 3. AI 활용 방식

모델: Anthropic Claude API `claude-opus-5-5` (이미지·PDF 입력, JSON 스키마 구조화 출력). [AI 분석 · 콘텐츠 생성] 버튼 1회 = 기본 호출 2회 (생성 결과에 빈칸이 있으면 1회 추가).

```
[입력] 제품 자료(+PDF 선택) + 가이드라인 (기본값 내장) + 사진 최대 5장
   │
   ▼ ① 분석 호출 (/api/analyze, 기본 effort low)
   │    · 제품 자료 → 차별점 카드(특징 / 이익 / 원문 근거), 일반 방식 vs 티링크 비교표
   │    · 사진 이미지 인식 → 보이는 것·증명 차별점·미션 번호·배치 단락·캡션·개인정보 경고
   │    · 가이드라인 원문 → 키워드·태그·미션·구성·하단 정보 목록(JSON)
   │
   ▼ ② 생성 호출 (/api/generate, 기본 effort low)
   │    · 블로그 리뷰(추천 구성 순서, 사진 위치, 근거 태그 ⟦자료⟧ ⟦가이드라인⟧ ⟦사진N⟧, 협찬 표시, 하단 정보)
   │    · 카드뉴스 4장(1장 문제 제기 → 4장 상담 문의·도입 절차) + 인스타그램 캡션
   │    · 미션 11개 자체 판정(본문 인용), 근거 없는 표현 "확인 필요" 경고
   │    · 서버 빈칸 검사: 제목·첫 문단·단락·결론·하단 정보·태그·카드뉴스 4장·캡션·미션 중
   │      빈칸이 있으면 effort medium으로 1회 재생성
   │
   ▼ ③ 브라우저 코드 검수 (AI 아님, 같은 입력이면 같은 결과)
   │    · 코드 검사 40개: 필수 키워드 3 + 서브 키워드 10 + 태그 19 + 본문 구성 5 + 하단 정보 3
   │    · + AI 미션 판정 11개 = 51개 조건 충족률
   │    · 추가 점검(점수 미반영): 제목·첫 문단 키워드, 사진 배치 수, 협찬 표시, 최상급·단정 표현 스캔
   │
   ▼ ④ Canvas → 올린 사진 위에 문구를 얹은 카드뉴스 PNG 4장
```

| 일 | 담당 | 이유 |
| --- | --- | --- |
| 차별점 추출, 사양 → 고객 이익 변환 | AI | 사양을 고객의 언어로 바꾸는 일은 규칙으로 할 수 없음 |
| 사진 인식, 미션 증거 판단, 배치 | AI (이미지 입력) | 사진이 어떤 장점·미션을 증명하는지 판단해야 함 |
| 블로그·카드뉴스 문구 | AI | 미션과 구성을 지키며 사용 후기체로 써야 함 |
| 미션 11개 판정 | AI (본문 인용 필수) | 의미 판단. 인용을 붙여 담당자가 바로 확인 |
| 키워드·태그·구성·하단 정보 40개 | 코드 | 셀 수 있는 조건은 코드가 정확함 |
| 최종 승인 | 담당자 | 담당자를 "작성자"에서 "승인자"로 |

## 4. 일반 생성형 AI 대비 차이

| 항목 | 채팅형 생성 AI에 직접 요청 | 티링크 프로모 스튜디오 |
| --- | --- | --- |
| 자료·가이드라인 | 매번 붙여 넣기 | 기본값 내장, 사진만 올림 |
| 차별점 근거 | 출처 없이 문장 생성 | 카드마다 자료 원문 인용, 본문 사실 문장에 근거 출처 태그(자료·가이드라인·사진) |
| 사진 | 사람이 고르고 배치 | 사진별 증명 차별점·미션·배치 제안, 요구 화면이 아니면 구분, 개인정보 경고 |
| 카드뉴스 | 문구만 출력 | 사진 위에 문구를 얹은 PNG 4장 |
| 가이드라인 준수 | 사람이 51개 조건을 직접 대조 | 검수표 1장 (코드 40개 + AI 미션 11개, 미션 본문 인용) |
| 과장·근거 없는 수치 | 그대로 섞임 | "확인 필요" 경고, 최상급 표현 코드 스캔 |

## 5. 실행 방법

**필요한 것:** Node.js 20.12 이상(`.env` 자동 읽기 `process.loadEnvFile` 사용), Anthropic API 키. API는 사용량만큼 요금이 발생합니다 (1회 약 0.37달러 추정: 실측 입력 약 3.3만·출력 약 1.2만 토큰 × Opus 5.5 단가 입력 $4·출력 $20 / 100만 토큰).

```bash
cd tlink-note
npm install
cp .env.example .env          # Windows 명령 프롬프트: copy .env.example .env
```

`.env`에 키를 넣습니다.

```
ANTHROPIC_API_KEY=여기에_본인_API_키
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

- 선택 설정: `CLAUDE_MODEL`, `ANALYZE_EFFORT`, `GENERATE_EFFORT` (코드 기본값은 분석 low, 생성 low. 생성 결과에 빈칸이 있으면 medium으로 1회 자동 재생성)
- 소요 시간: 버튼 1회에 89.5~166.4초 실측 (effort에 따라 다름, 7장 참고)

**사용 순서**

1. 왼쪽 ① 제품 자료, ② 홍보 가이드라인에는 티링크 기본값이 채워져 있습니다. 필요하면 수정하거나 제품 자료 PDF를 첨부합니다.
2. ③ 현장사진·화면 캡처를 최대 5장 올립니다.
3. [AI 분석 · 콘텐츠 생성]을 누르면 진행 표시에 단계별 소요 초가 나옵니다.
4. 오른쪽 탭에서 결과를 확인하고 블로그 본문을 복사하거나 카드뉴스 PNG를 내려받습니다.

**스모크 테스트** (서버 실행 중, 실제 API 2회 호출로 비용 발생)

```bash
node scripts/smoke-test.mjs <사진폴더> [결과저장.json]
```

소요 초, 토큰, 키워드·태그·구성·미션 충족 수, 경고 수를 JSON으로 출력합니다.

> **주의**
> - `.env`(API 키)는 `.gitignore`에 포함되어 저장소에 올라가지 않습니다.
> - 올린 사진은 Claude API로 전송됩니다. 고객 이름·전화번호가 보이는 화면은 가린 뒤 올리세요.

## 6. 폴더 구조와 자료 출처

```
tlink-note/
├─ server.js              # Express 서버. /api/analyze, /api/generate(빈칸 검사·재생성), /api/samples
├─ prompts.js             # 분석·생성 시스템 프롬프트와 JSON 스키마
├─ package.json
├─ .env.example           # 환경변수 예시 (.env는 커밋 제외)
├─ scripts/smoke-test.mjs # 서버에 샘플 자료+사진을 넣어 끝까지 실행하고 결과 요약
├─ public/
│  ├─ index.html          # 왼쪽 입력 + 진행 표시 + 오른쪽 결과 탭 5개
│  ├─ app.js              # API 호출, 탭 렌더링, 코드 검수(runChecks), Canvas 카드뉴스
│  └─ style.css
└─ data/samples/
   ├─ product.md          # 기본값: 티링크 비즈레코딩 제품 자료 요약 텍스트
   └─ guideline.md        # 기본값: 티링크 2026년 11월 홍보 가이드라인 텍스트
```

**후원사 원본 자료는 저장소에 없습니다.** 티링크가 제공한 원본 파일(비즈레코딩 제안서, 휴대폰버전 매뉴얼, 홍보 가이드라인 원본)과 테스트에 쓴 화면 캡처 5장은 포함하지 않았습니다. 저장소에는 앱 기본값으로 쓰는 텍스트(`data/samples/`)만 있습니다.

| 회차 | 생성 effort | 분석 | 생성 | 합계 | 결과 |

## 8. 한계와 다음 버전

**한계**

- 블로그·SNS 자동 게시는 없습니다 (MVP 제외). 복사·PNG 다운로드 후 담당자가 게시합니다.
