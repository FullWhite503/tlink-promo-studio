# 티링크 프로모 스튜디오

> 제품 자료·홍보 가이드라인·현장사진을 넣으면, AI가 기술 차별점을 근거와 함께 뽑고 사진 배치까지 맞춘 **네이버 블로그 리뷰**와 **인스타그램 카드뉴스 4장**을 만든 뒤, **가이드라인 준수 여부를 자동으로 검수**하는 마케팅 도구입니다.

- **과제:** AISH 5회 스마트워크톤 본선 트랙 A, 티링크 과제. "티링크의 제품과 기술적 차별점을 AI가 분석하고, 현장 사진과 제품 정보만으로 고객의 관심을 끌 수 있는 홍보 콘텐츠를 자동 생성하는 마케팅 솔루션"
- **대상 제품:** 티링크 비즈레코딩. 휴대폰·인터넷전화·PC 소프트폰 통합 통화녹음, STT, AI 통화요약, CRM, 종합리포트 "티링크노트"
- **1차 사용자:** 블로그 체험단·대리점에 홍보 가이드라인을 배포하고 돌아온 원고를 검수하는 1~2명 규모 마케팅팀
- **시연 영상:** 【업로드 후 기입】

---

## 1. 해결하는 문제

티링크 2026년 11월 홍보 가이드라인 1건에 담긴 조건은 다음과 같습니다.

| 조건 | 개수 | 예시 |
| --- | --- | --- |
| 필수 키워드 (제목과 본문 모두) | 3 | 통화요약, 콜센터 프로그램, 업무자동화 |
| 서브 키워드 | 10 | 녹취, 경영대시보드, CRM, STT, 음성요약 등 |
| 태그 | 19 (중복 제외) | #콜센터프로그램 #영업사원 통화관리 #종합리포트 등 |
| 강조 미션 | 11 | 제목·첫 문단에 키워드 4종, 화면 이미지 5종을 순서대로 소개, AES256·SHA256 보안 소개 등 |
| 추천 본문 구성 | 5단 | 기존 영업관리의 문제 → 휴대폰·인터넷전화 동시 녹음 → AI 자동 기록과 요약 → 영업사원 관리 → 경영진 종합 리포트 |
| **합계** | **48** | 여기에 하단 정보(홈페이지, 공식 블로그, 상담 문의)가 더해짐 |

이 때문에 생기는 문제:

1. **조건이 너무 많다.** 작성자는 48개를 다 지키기 어렵고, 마케팅 담당자는 원고마다 48개 항목을 눈으로 대조한다.
2. **사양이 고객의 언어로 바뀌지 않는다.** "인터넷전화+휴대폰+PC 소프트폰 통합 녹취, 99% 녹취 성공률, AES256 암호화"(제품 자료) 같은 사양이 "외근 영업 통화까지 한 화면에서 관리된다"는 이익으로 연결되지 않으면 관심을 끌지 못한다.
3. **사진이 글과 따로 논다.** 가이드라인은 휴대폰 통화 화면 → 녹취 목록 → AI 통화요약 → 직원별 통계 → 종합리포트 순서로 이미지를 요구하지만, 사진을 고르고 배치하는 일은 수작업이다.
4. **일반 생성형 AI는 검수를 해 주지 않는다.** 매번 자료와 가이드라인을 다시 넣어야 하고, 자료에 없는 수치나 "국내 1위" 같은 과장 표현이 섞여도 걸러 주지 않는다.

## 2. 핵심 기능 3개 (1단계 기획서 주요 기능과 1:1)

| # | 기능 | 입력 → 출력 | 화면 탭 |
| --- | --- | --- | --- |
| 1 | **기술 차별점 분석 카드** | 제품 자료(텍스트, PDF 선택) → 차별점 4~6개. 카드마다 "기술 특징 / 고객 이익 / 자료 원문 근거", "일반적인 방식 vs 티링크" 비교표 | ① 차별점 카드 |
| 2 | **현장사진 분석·배치** | 현장사진·화면 캡처 1~5장 → 사진별 설명, 화면 유형, 증명하는 차별점, 블로그 배치 단락, 캡션, 개인정보 노출 경고 | ② 사진 분석·배치 |
| 3 | **가이드라인 맞춤 콘텐츠 생성 + 자동 검수** | 위 결과 + 가이드라인 → 네이버 블로그 리뷰(사진 위치, 필수 키워드 하이라이트, 근거 태그, 본문 복사), 인스타그램 카드뉴스 4장(1080×1080 PNG)과 캡션, 검수표(충족률, 키워드·태그·하단 정보·미션 11개, "확인 필요" 경고) | ③ 블로그 리뷰, ④ 카드뉴스, ⑤ 가이드라인 검수표 |

## 3. AI 활용 방식

모델: Anthropic Claude API `claude-opus-5-5` (이미지·PDF 입력, JSON 스키마 구조화 출력). [AI 분석 · 콘텐츠 생성] 버튼 1회 = API 호출 2회.

```
[입력] 제품 자료(+PDF) + 가이드라인 + 사진(최대 5장)
   │
   ▼ ① Claude 호출 1: 분석  (/api/analyze)
   │    · 제품 자료 → 차별점 카드 (특징 / 이익 / 원문 근거), 일반 방식 vs 티링크 비교
   │    · 사진 이미지 인식 → 사진별 설명·화면 유형·증명 차별점·배치 단락·개인정보 경고
   │    · 가이드라인 원문 → 키워드·태그·미션·구성·하단 정보 목록으로 구조화
   │
   ▼ ② Claude 호출 2: 생성  (/api/generate)
   │    · 블로그 리뷰 (추천 구성 순서, 사진 위치, 문장별 근거 태그 ⟦자료⟧ ⟦가이드라인⟧ ⟦사진N⟧)
   │    · 카드뉴스 4장 문구 + 인스타그램 캡션
   │    · 미션 11개 자체 판정 (본문 인용 포함), 근거 없는 표현 경고
   │
   ▼ ③ 브라우저 코드 검수 (AI 아님, 같은 입력이면 항상 같은 결과)
   │    · 필수 키워드 제목/본문 포함, 제목·첫 문단 키워드, 서브 키워드·태그 포함 수,
   │      하단 정보, 사진 배치 수 → 미션 판정과 합쳐 충족률(%) 계산
   │
   ▼ ④ Canvas 렌더링 → 올린 사진 위에 문구를 얹은 카드뉴스 PNG 4장
```

| 일 | 담당 | 이렇게 나눈 이유 |
| --- | --- | --- |
| 차별점 추출, 사양 → 고객 이익 변환 | AI | 사양을 고객의 언어로 바꾸는 일은 규칙으로 할 수 없다 |
| 사진 내용 인식과 배치 | AI (이미지 입력) | 사진이 어떤 장점을 증명하는지 판단해야 한다 |
| 블로그 리뷰·카드뉴스 문구 작성 | AI | 미션과 구성을 지키면서 실제 사용 후기체로 써야 한다 |
| 미션 11개 충족 판정 | AI (본문 인용 필수) | "자연스럽게 강조했는가"는 의미 판단이다. 인용을 붙여 사람이 바로 확인할 수 있게 한다 |
| 키워드·태그·하단 정보 포함 확인 | 코드 | 셀 수 있는 조건은 AI보다 코드가 정확하다 (AI + 규칙 이중 점검) |
| 근거 없는 수치·최상급 경고 | AI (자료 원문과 대조) | 자료에 없는 표현은 "확인 필요"로 표시해 표시·광고 위험을 줄인다 |

## 4. 일반 생성형 AI 대비 차별점

| 항목 | 채팅형 생성 AI에 직접 요청 | 티링크 프로모 스튜디오 |
| --- | --- | --- |
| 자료·가이드라인 입력 | 매번 붙여 넣기 | 티링크 제품 자료와 11월 가이드라인 기본값 내장 |
| 차별점 근거 | 출처 없이 문장 생성 | 카드마다 자료 원문 인용, 본문 문장마다 근거 태그 |
| 사진 활용 | 사람이 고르고 배치 | 사진별 증명 차별점과 블로그 배치 단락 자동 제안, 개인정보 노출 경고 |
| 카드뉴스 | 문구만 출력 | 올린 사진 위에 문구를 얹은 PNG 4장 |
| 가이드라인 준수 확인 | 사람이 48개 조건을 직접 대조 | 검수표 1장 (코드 카운트 + AI 판정과 본문 인용, 충족률) |
| 과장·근거 없는 수치 | 그대로 섞여 나옴 | "확인 필요" 경고로 따로 표시 |

## 5. 실행 방법

**필요한 것:** Node.js 20.12 이상(`.env` 자동 읽기에 필요), Anthropic API 키. API는 호출량만큼 요금이 발생합니다 (1회 실행 = 호출 2회).

```bash
cd tlink-note
npm install
```

`.env.example`을 `.env`로 복사하고 키를 넣습니다.

```bash
cp .env.example .env          # Windows 명령 프롬프트: copy .env.example .env
```

```
ANTHROPIC_API_KEY=여기에_본인_API_키
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 선택 설정(`CLAUDE_MODEL`, `ANALYZE_EFFORT`, `GENERATE_EFFORT`)은 `.env.example`에 설명이 있습니다.

**사용 순서**

1. 왼쪽 ① 제품 자료, ② 홍보 가이드라인에는 티링크 기본값이 채워져 있습니다. 필요하면 수정하거나 제품 자료 PDF를 첨부합니다.
2. ③ 현장사진·화면 캡처를 최대 5장 올립니다 (선택).
3. [AI 분석 · 콘텐츠 생성]을 누릅니다. 진행 표시에 단계별 소요 시간이 나옵니다 (전체 약 30~90초, 추정).
4. 오른쪽 탭에서 결과를 확인하고 블로그 본문을 복사하거나 카드뉴스 PNG를 내려받습니다.

> **주의**
> - `.env`(API 키)는 `.gitignore`에 포함되어 저장소에 올라가지 않습니다.
> - 올린 사진은 Claude API로 전송됩니다. 고객 이름·전화번호가 보이는 화면은 가린 뒤 올리세요.

## 8. 한계와 다음 계획

**한계**

- AI의 미션 판정은 참고용입니다. 본문 인용을 함께 보여 주지만 최종 판단은 담당자가 합니다.
- 코드 검수의 기준 목록(키워드·태그·하단 정보)은 호출 1에서 AI가 가이드라인 원문을 옮겨 만듭니다. 포함 여부 판정은 코드가 하지만, 목록 누락 여부는 검수표의 항목을 보고 사람이 확인해야 합니다.
- 티링크 2026년 11월 가이드라인 형식을 기준으로 만들었습니다. 형식이 다른 가이드라인은 추가 검증이 필요합니다.
- 사진 속 개인정보는 AI가 발견하면 "게시 전 흐림 처리 필요"로 경고하지만, 자동으로 가리지는 않습니다.
- 생성에 30~90초가 걸립니다 (추정, 측정 후 갱신).
- 데모 서버 없이 로컬에서 실행하며, 본인 API 키가 필요합니다.

**이번에 만들지 않은 것** (1단계 기획서와 동일): 블로그·SNS 자동 게시, 영상 생성, 다국어 번역, 회원가입·로그인, 게시 후 조회수 분석

**다음 계획**

1. **원고 검수 모드:** 체험단·대리점이 보낸 원고를 붙여 넣으면 같은 48개 조건 검수표로 점검
2. **월별 가이드라인 저장:** 매달 바뀌는 가이드라인을 저장하고 불러오기
3. **채널 추가:** 영업 문자, 숏폼 영상 대본
4. **개인정보 자동 흐림:** 사진 속 전화번호·이름 영역 자동 가림
